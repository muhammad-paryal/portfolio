# Muhammad Paryal | IT Portfolio

Personal portfolio website built with HTML, CSS and JavaScript for the Parallel and Distributed Computing additional activity, Department of Software Engineering, University of Sindh.

## Features
- Responsive layout (desktop, tablet, mobile)
- All required sections: About, Education, Skills, Projects, Case Study, Experience, Certifications, CV, Contact
- Accessible navigation and image alt text

## Run locally
1. Clone the repo: `git clone https://github.com/muhammad-paryal/portfolio.git`
2. Open `index.html` in a browser (no build step needed).

## Deployment
Deployed on Vercel through the GitHub integration. Every push to `main` redeploys the site.

## Structure
- `index.html` – page content
- `style.css` – styling
- `script.js` – mobile menu
- `assets/` – profile photo, project screenshots, `cv.pdf`
